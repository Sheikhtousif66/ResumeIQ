# ResumeIQ

AI-Powered Resume Screening & Candidate Matching System built with Flask and Sentence Transformers.

## Features

- Upload PDF & DOCX resumes
- AI-powered resume matching
- Candidate information extraction
- Create and manage jobs
- Candidate dashboard
- Search candidates
- Delete jobs and candidates

## Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- Sentence Transformers
- HTML
- CSS
- Jinja2

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/ResumeIQ.git

cd ResumeIQ

pip install -r requirements.txt

python backend/run.py
```
